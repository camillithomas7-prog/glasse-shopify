# glassé — Shopify theme

Generated from the local landing `~/glasse-landing` with `python3 build.py`.

- Home and the main product (`glasse-salmon-dna-jelly-pads`) render the full landing.
- Cart = drawer with Shopify Ajax cart: bundle upgrade, Spot Dots add-on, pre-checkout offer (extra jar $18).
- Products: `glasse-products.csv` (images served from `product-images/` in this repo).
- Theme settings: product handles, free-shipping threshold/fee (display), company data.
